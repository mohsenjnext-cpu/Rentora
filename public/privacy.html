Rentora Privacy Policy

Last updated: September 12, 2026

Rentora is a decentralized peer-to-peer rental marketplace built on the Pi Network ecosystem. This Privacy Policy outlines how your information is handled when using the Rentora application.

1. Authentication & Information Collected

Rentora uses Pi SDK 2.0 for exclusive authentication. We do not collect passwords or private seed phrases. The only user data received from the Pi Network SDK upon user consent includes:

  • Pi Username and unique Pi User ID (UID)
  • Authentication scope permissions granted by the user via the Pi Browser

2. Marketplace Data

When you use Rentora to list or rent items, the following data is processed to facilitate peer-to-peer transactions:

  • Item listings (title, category, description, photos, location, daily rental price)
  • Rental requests, booking dates, and handover/return status
  • In-app direct communication messages between verified Pioneers for handover logistics
  • Ratings and reviews submitted after rental completion

3. Pi Payments & Financial Privacy

All payments are conducted exclusively in Pi cryptocurrency via the official Pi SDK and Pi Blockchain. Rentora does not store or process fiat currency, credit card details, or banking information. Platform fee transactions are verified cryptographically through the Pi Network API.

4. Data Storage & Security

All data is securely stored and processed within high-security cloud infrastructure using Cloudflare Workers and D1 SQL databases with TLS encryption. We do not sell or rent user data to third parties or advertisers.

5. Contact Us

If you have any questions regarding this Privacy Policy, please contact the development team at developer@rentora.app or through the official Pi Network Developer Portal.
